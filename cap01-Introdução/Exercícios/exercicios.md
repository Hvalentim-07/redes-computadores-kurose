# R01 - Qual é a diferença entre um hospedeiro e um sistema final? Cite os tipos de sistemas finais. Um servidor Web é um sistema final?

---

Não há diferença, sendo todo um end system um host e todo host um end system. Computadores, Celulares, Televisões e varias outras coisas são exemplos de end systems. Sim, um servidor é um end system pois pertence a borda da rede.

# R02 - A palavra protocolo é muito usada para descrever relações diplomáticas. Como a Wikipédia descreve um protocolo diplomático?

---

Protocolos diplomáticos são um conjunto de regras que os chefes de Estado devem seguir para estabelecer uma relação diplomática entre os países preservando o respeito mútuo.

---

# R03 - Por que os padrões são importantes para os protocolos?

---

Para que dispositivos de fabricantes diferentes (computadores, celulares, roteadores) consigam se comunicar sem problemas.

# R05 - A taxa de transmissão HFC é dedicada ou é compartilhada entre usuários? É possível haver colisões na direção provedor-usuário de um canal HFC? Por quê?

---

A taxa de transmissão é compartilhada, os usuários compartilham de um mesmo link e os pacotes são enviados em diferentes frequências. Não, o provedor tem o controle de tudo o que é transmitido nessa direção.
