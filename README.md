# Redes de Computadores e a Internet - Kurose & Ross

Esse repositório é dedicado ás minhas resoluções dos exercícios de fixação e problemas do livro **"Redes de Computadores e a Internet" vol-8** (James F. Kurose e Keith W. Ross).

O objetivo desse espaço é documentar meus estudos, fixar os conceitos práticos e teóricos da área de redes e compartilhar as soluções.
